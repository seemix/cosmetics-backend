## Якщо `accountingStartAt` порожнє після вмикання

Причина: прапорець увімкнули на старій збірці без хука. Знімати й ставити прапорець не варто,
бо дата стане «зараз», а замовлення в проміжку стануть історичними. Краще записати фактичний час
вмикання: це `createdAt` першого замовлення з `accounting.stockTracked: true`.

```js
db.globals.updateOne(
  { globalType: 'accounting-settings', accountingStartAt: { $exists: false } },
  { $set: { accountingStartAt: ISODate('<createdAt першого облікового замовлення>') } }
)
```

- Повне відновлення лише з резервної копії кроку 0; замовлення, створені після копії, переносяться вручну.
